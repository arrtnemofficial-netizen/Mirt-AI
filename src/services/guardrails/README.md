# 🛡️ Guardrails Service — Охоронець

> **Роль:** "Bodyguard" (Охоронець)
> **Відповідальність:** Захист системи від зациклень, галюцинацій станів та аномальної поведінки LLM.

Цей модуль діє як **"Запобіжник"** (Circuit Breaker) для діалогів. Він перехоплює управління у `ConversationHandler` *після* того, як агент згенерував відповідь, але *до* того, як вона буде збережена.

---

## 🔍 Як це працює? (Loop Detection)

Головний механізм — **Fingerprinting** (Зняття відбитків).

### 1. State Fingerprint
Ми генеруємо унікальний хеш (SHA-256) поточного стану діалогу, враховуючи:
*   Поточний State (`STATE_X...`)
*   Фазу діалогу (`INIT`, `DISCOVERY`...)
*   Список вибраних/запропонованих товарів.
*   Дані клієнта (ім'я, телефон).
*   Статус оплати.

Якщо хеш стану **не змінюється** протягом декількох кроків підряд, це означає, що **бот застряг** (тупцює на місці).

### 2. Три Рівні Захисту (Thresholds)

| Кількість повторів | Реакція | Опис |
| :--- | :--- | :--- |
| **5 разів** | 🟡 **Warning** | Система фіксує потенційну проблему в логах/метриках. Користувач нічого не помічає. |
| **10 разів** | 🟠 **Soft Recovery** | **Скидання до початкового стану.** Система примусово переводить діалог в `INIT`. Це дає шанс почати з чистого аркуша. |
| **20 разів** | 🔴 **Escalation** | **Виклик людини.** Бот переходить у стан `COMPLAINT` і кличе менеджера. Це "аварійний стоп". |

---

## 🚦 Валідація Станів

Крім циклів, модуль перевіряє "легальність" станів:

1.  **Dialog Phase Check:** Перевіряє, чи фаза (`dialog_phase`) входить у дозволений список (`VALID_DIALOG_PHASES` з `core.state_machine`). Якщо LLM вигадала нову фазу — вона буде нормалізована до допустимої для поточного стану.
2.  **State Logic Check:** Перевіряє коректність Enum значень станів.

---

## 🛠️ Використання

Цей сервіс викликається виключно з `conversation.py`:

```python
from src.services.guardrails.loop_detector import apply_loop_protection

# ... після виклику агента ...
result_state = apply_loop_protection(
    session_id=session_id,
    before_state=state_before_agent,
    after_state=state_from_agent,
    user_text=user_message
)
```

## 📋 Пам'ятка
*   Якщо бот раптово почав відповідати "Привіт" посеред розмови — це спрацював **Soft Recovery (10 loops)**.
*   Якщо бот кличе менеджера без причини — це **Escalation (20 loops)**.
